# NyangSquad-version

냥냥방어대(`com.innoversegames.nyangSquad`)의 강제 업데이트 확인용 최신 버전 정보입니다.

- 게임을 켤 때 `version.json`을 읽어, 설치된 앱의 버전 코드가 `latestVersionCode`보다 낮으면 "새 버전이 있어요" 창을 띄우고 스토어로 보냅니다 (업데이트 전에는 플레이 불가).
- 구글 플레이에 새 버전이 배포된 **뒤에** `latestVersionName`, `latestVersionCode`, `updatedAt`을 고칩니다.
- 파일을 못 읽거나 인터넷이 없으면 막지 않고 그대로 플레이합니다.

## hottime.json (핫타임 지급 목록)

게임의 **핫타임** 시각과 선물 목록입니다. 이 파일만 고쳐서 올리면 **앱 업데이트 없이** 바뀝니다 (게임을 켤 때 읽고, 켜 둔 동안은 10분마다 다시 읽음. 인터넷이 안 되면 마지막으로 읽은 목록, 한 번도 못 읽었으면 기본값 = 매일 9 · 12 · 18 · 20시 통조림 30개).

```json
{
  "durationMin": 120,
  "slots": [
    { "id": "h09", "hour": 9, "minute": 0, "rewards": [ { "kind": "tuna", "n": 30 } ] }
  ]
}
```

- `durationMin`: 시작한 뒤 몇 분 안에 받을 수 있는지 (기본 120분).
- `slots`: 하루에 열리는 시각 목록 (최대 12개, 시각순 자동 정렬). 시각은 폰의 현지 시각 기준.
  - `id`: 시각마다 **겹치지 않는 이름**. 하루 한 번 받음 기록이 이 이름으로 저장되므로, 바꾸면 그 시각은 새 시각으로 취급되어 다시 받을 수 있음.
  - `hour`(0~23), `minute`(0~59): 열리는 시각.
  - `rewards`: 그 시각에 주는 선물 목록 (여러 개 가능). `kind` = `tuna`(통조림) · `gold`(골드) · `gem`(보석) · `material`(분해 재료) · `piece`(캐릭터 조각), `n` = 개수.
- 모양이 틀리면(잘못된 JSON, 시각 없음 등) 그 파일은 무시하고 마지막으로 읽은 목록을 씁니다. 올리기 전에 JSON 문법을 꼭 확인하세요.
- 푸시 알림(폰에 예약하는 알림)도 이 목록의 시각에 맞춰 게임을 켤 때마다 다시 예약됩니다. 알림을 이미 예약한 시각은 게임을 다시 켜야 바뀐 목록으로 갱신됩니다.

## events.json (시즌 · 이벤트)

게임 미션 화면의 **[이벤트] 탭**에 나오는 기간 한정 이벤트 목록입니다. 이 파일만 고쳐서 올리면 **앱 업데이트 없이** 시작 · 끝 날짜, 목표, 보상, 글이 바뀝니다 (1.0.13 이상. 게임을 켤 때 읽고, 켜 둔 동안은 10분마다 다시 읽음. 인터넷이 안 되면 마지막으로 읽은 것, 한 번도 못 읽었으면 이벤트 없음). 지금 시각이 `start` ~ `claimEnd` 안인 이벤트만 보이고, 하나도 없으면 탭이 사라집니다. 새 이벤트가 열리면 미션 메뉴에 빨간 점이 뜹니다.

```json
{
  "events": [
    {
      "id": "s1_winter",
      "title": "냥냥 겨울 시즌",
      "titleEn": "Nyang Winter Season",
      "start": "2026-11-23 09:00",
      "end": "2026-12-07 09:00",
      "tasks": [
        { "id": "t1", "stat": "plays", "target": 30, "reward": { "kind": "gold", "n": 3000 } },
        { "id": "t2", "stat": "wins",  "target": 20, "text": "전투 20판 승리", "textEn": "Win 20 battles", "reward": { "kind": "material", "n": 300 } }
      ],
      "bonus": { "kind": "gem", "n": 10 }
    }
  ]
}
```

- `id`: 이벤트마다 **겹치지 않는 이름**. 진행 횟수 · 받음 기록이 이 이름으로 저장되므로, **바꾸면 새 이벤트로 취급**(기록 초기화)합니다. 진행 중에는 바꾸지 마세요. 같은 이름을 다음 이벤트에 다시 쓰지 마세요.
- `title`: 이벤트 제목 (없으면 "시즌 이벤트"). `titleEn` · `titleJa` · `titleZhHans` · `titleZhHant` 는 다른 언어 (없으면 한국어).
- `start` · `end`: `"2026-11-23 09:00"` 또는 `"2026-11-23"` 모양, 폰의 현지 시각. 시작 ~ 끝 사이에 한 활동만 목표에 모입니다.
- `claimEnd`: (선택) 끝난 뒤에도 보상을 받을 수 있는 마감. 없으면 `end` 와 같음.
- `tasks`: 목표 목록 (1~12개). 목표마다
  - `id`: 이벤트 안에서 겹치지 않는 이름.
  - `stat`: 모으는 활동 — `plays`(전투 플레이) · `wins`(전투 승리) · `kills`(몬스터 처치) · `cards`(레벨업 카드 선택) · `bosses`(보스 처치) · `ads`(광고 시청) · `enhance`(장비 강화) · `salvage`(장비 분해) · `corefuse`(코어 합성) · `heroup`(캐릭터 강화) · `missions`(미션 완료).
  - `target`: 목표 횟수.
  - `reward`: `kind` = `gold`(골드) · `gem`(보석) · `tuna`(통조림) · `material`(분해 재료) · `piece`(캐릭터 조각), `n` = 개수.
  - `text`: (선택) 목표 문장. 없으면 `stat` · `target` 으로 자동 ("전투 30판 플레이"). `textEn` · `textJa` · `textZhHans` · `textZhHant` 는 다른 언어.
- `bonus`: (선택) 목표를 **전부 받으면** 주는 보너스 (`kind`, `n`).
- 보상 가치 기준 (게임 안 기준): 골드 1원 · 보석 500원 · 통조림 10원 · 분해 재료 10원 · 캐릭터 조각 10원. 일일 미션 전체가 하루 약 3,000원어치입니다.
- 모양이 틀린 이벤트 · 목표(끝이 시작보다 빠름, 모르는 `stat`, 개수 0 등)는 건너뛰고 나머지를 씁니다. 파일 전체가 잘못된 JSON 이면 마지막으로 읽은 목록을 씁니다. 올리기 전에 JSON 문법을 꼭 확인하세요.
